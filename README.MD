# Теорія баз даних
## Налаштування проєкту після клонування репозиторію
Додаємо до проєкту базу даних (один з варіантів)
а) Проєкт (ПКМ) - Add - New Item - [Data] Service-based Database
б) Підключити наявну БД: Tools - Connect to database - ...

Запускаємо скрипт створення таблиць ddl/InstallTables.sql
!! якщо БД не є порожньою, то наявні таблиці будуть видалені
- підключаємось до БД:
 = відкриваємо скрипт (файл)
 = DblClick по файлу БД (Database1.mdf)
 = у редакторі SQL натискаємо кнопку "Підключення"
 = вибираємо сервер (MS SQL LocalDB) і відповідну БД
- виконуємо команди скрипту

Вносимо дані до таблиць
- відкриваємо скрипт (файл) dml/SeedTables.sql
- підключаємось до БД
- виконуємо команди скрипту
